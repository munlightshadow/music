# Шаблон рабочего модуля (1–20)

## Фаза 1. Receptive

Теория + тренажёры. Автопроверка допустима.

| Линия | Что входит | Ограничение |
| --- | --- | --- |
| Лексика | Единицы темы модуля, сочетаемость, при необходимости синонимы/антонимы, фразовые глаголы | Только тематическое содержание этого модуля + повтор ядра |
| Грамматика | 1 основной блок (+ точечный сопутствующий) | Не складывать в модуль «всю грамматику ЕГЭ» |
| Словообразование | Узкий набор аффиксов | Наращивается по модулям |
| Чтение | Одна ведущая стратегия + текст(ы) на тему модуля | Объём к концу курса — до 900 слов, как в кодификаторе |
| Аудирование | Одна ведущая стратегия + аудио на тему модуля | К концу курса — до 3,5 минут |
| Фонетика | 1–2 конкретных навыка | Имитация + различение; не абстрактная «постановка произношения» |

## Фаза 2. Productive

Порядок из вводного видео:

1. Групповой урок Zoom — живая речь на материале модуля.
2. Три работы тьютору:
   - задание 37 — электронное личное письмо;
   - задание 38 — эссе по таблице / графику / диаграмме (элементы проекта и делового письма; CV нет);
   - задание 4 — монолог по картинкам в логике голосового сообщения другу.
3. Итоговый тест модуля — автопроверка.

Тема письма, эссе и говорения должна опираться на **тематическое содержание модуля**, чтобы лексика фазы 1 имела куда применяться.

## Правила проверки внутри модуля

| Критерий | С какого момента | Как |
| --- | --- | --- |
| РКЗ | С первой продуктивной работы курса | Полностью, по бланку ЕГЭ |
| Организация | С первой продуктивной работы курса | Полностью, по бланку ЕГЭ |
| Язык | Накопительно | Комментируем темы модулей 1…N (год 1) или вводный формат + темы 11…N (год 2) |
| Орфография и пунктуация письма | С вводного модуля: оформление 37 | Комментируем пройденные правила оформления + написание изученных слов |

Тьютор всегда держит рядом [накопительный список](../03-curriculum/cumulative-checklist.md) на номер текущего модуля.

## Карточка модуля — обязательные поля

Для каждого модуля 1–20 заполняется:

- номер и короткое имя;
- год (1 или 2);
- тема речи (буквы А–С кодификатора);
- грамматика (коды 2.4.x);
- лексический фокус (коды 2.3.x);
- словообразование (коды 2.3.11.x);
- фонетика;
- стратегия чтения;
- стратегия аудирования;
- продуктивные формулировки 37 / 38 / 4;
- что добавляется в накопительный список тьютора.

Черновая заполненная сетка: [module-index.md](../03-curriculum/module-index.md).

## Вводный модуль — не по этому шаблону

Вводный модуль не гоняет тренажёры кодификатора как рабочий. Он даёт навигацию:

- как устроен экзамен;
- как устроен курс;
- как проверяют 37, 38 и задание 4;
- накопительный принцип фидбека;
- куда возвращаться перед сдачей работ.
