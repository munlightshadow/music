# Грамматика (раздел 2.4)

Колонка «ЕГЭ» собрана по итоговому своду исходника.  
«Частично» — по прямым пометам автора.  
Элементы из блока «что НЕ входит» итогового свода помечены как вне ЕГЭ, даже если они есть в общем списке программы.
