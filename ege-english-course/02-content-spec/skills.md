# Стратегии и умения по видам речевой деятельности

## Говорение (1.1.1–1.1.2)

### Диалогическая речь

- этикетный диалог;
- побуждение к действию;
- диалог-расспрос;
- обмен мнениями;
- комбинированный диалог;
- полилог.

В ЕГЭ это в первую очередь задания 2 и 3 устной части. Zoom закрывает живую диалогическую практику.

### Монологическая речь

- описание (предмет, местность, внешность, одежда, характер);
- повествование / сообщение;
- рассуждение с мнением и краткой аргументацией;
- пересказ прочитанного/прослушанного с отношением;
- устное представление проекта;
- сообщение в связи с текстом.

Объём программы (углублённый уровень): до 18 фраз.  
ЕГЭ, задание 4: **12–15 фраз**.

## Письменная речь (1.4.1–1.4.10)

На ЕГЭ два письменных продукта. Они не равны одному коду кодификатора один к одному.

| Код | Умение | На ЕГЭ / в курсе |
| --- | --- | --- |
| 1.4.1 | Анкеты и формуляры | программа, отдельным заданием не сдаём |
| 1.4.2 | Резюме (CV) | **нет.** Не входит ни в 37, ни в 38 |
| 1.4.3 | Электронное сообщение личного характера, до 140 слов | **задание 37** — каждый модуль |
| 1.4.4 | Заполнение таблицы по тексту | не входит по итоговому своду |
| 1.4.5 | Аннотация, рассказ, рецензия, статья до 250 слов | частично |
| 1.4.6 | Письменное представление проекта, до 180 слов | **элементы в задании 38**: тема проекта, данные опроса, вывод автора |
| 1.4.7 | Письмо о приёме на работу, до 140 слов | программа, отдельным заданием не сдаём |
| 1.4.8 | Официальное (деловое) письмо, до 180 слов | **элементы в задании 38**: нейтральный/официальный стиль, без разговорности. Отдельное деловое письмо не пишем. Оформление бланка 2.2.5 не требуем |
| 1.4.9 | Высказывание с рассуждением на основе таблицы/графики/диаграммы, до 250 слов | **ядро задания 38** — каждый модуль |
| 1.4.10 | Комментарий к информации/высказыванию/пословице/цитате | не входит по итоговому своду |

### Как это читать

- **37** = личное письмо (1.4.3).
- **38** = эссе по таблице/диаграмме (1.4.9) **с элементами делового письма (1.4.8) и проектной работы (1.4.6)**.
- **CV (1.4.2) в курсе и в экзаменационном контуре нет.**

Продуктивный контур тьютора по-прежнему **37 + 38 + задание 4**. Отдельные «напиши CV» и «напиши деловое письмо» в недельную сдачу не входят: нужные черты делового письма и проекта уже сидят внутри 38.
