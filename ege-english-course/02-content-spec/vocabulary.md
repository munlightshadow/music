# Лексика (раздел 2.3)

## Проверяемые элементы

| Код | Элемент |
| --- | --- |
| 2.3.1 | Распознавание и употребление лексических единиц (слова, многозначные слова, фразовые глаголы, словосочетания, речевые клише, средства логической связи) в рамках темы, с нормами сочетаемости |
| 2.3.2 | Многозначные единицы. Синонимы. Антонимы |
| 2.3.3 | Прилагательные на -ed и -ing (excited – exciting) |
| 2.3.4 | Наиболее частотные фразовые глаголы |
| 2.3.5 | Средства связи для целостности устного и письменного высказывания |

## Не проверяется в ЕГЭ

| Код | Элемент |
| --- | --- |
| 2.3.6 | Сокращения и аббревиатуры |
| 2.3.7 | Интернациональные слова |
| 2.3.8 | Омонимы |
| 2.3.9 | Идиомы. Пословицы |
| 2.3.10 | Элементы деловой лексики |

Непроверяемое **не ставим в обязательные тренажёры и не включаем в накопительный список тьютора**. Можно оставить как необязательный бонус года 2, если понадобится «живой язык».

## Норматив объёма

Не менее **1650** лексических единиц (слова, словосочетания, клише), включая **1350**, освоенных на уровне ООО.

Списков по модулям в исходниках нет — это отдельный производственный слой (см. [GAPS.md](../GAPS.md)).
