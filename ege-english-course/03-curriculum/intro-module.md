# Вводный модуль

Одинаковый для года 1 и года 2. Идёт **после** диагностики.

## Задачи модуля

1. Показать устройство ЕГЭ.
2. Показать устройство курса (рецептивная / продуктивная фаза).
3. Ввести критерии 37, 38 и задания 4.
4. Объяснить накопительный фидбек, чтобы ученик не ждал «исправьте всё сразу».
5. Выдать рабочие шаблоны трёх продуктов — без них нельзя честно проверять РКЗ с первого рабочего модуля.

## Состав, которого ещё нет и без которого модуль дырявый

- диагностике здесь не место — она уже пройдена, но ученику нужно **объявить результат**: «ты на годе 1, дальше модули 1–20» / «ты на годе 2, дальше 11–20»;
- одностраничные памятки: скелет письма 37; скелет эссе 38 в официальном стиле по таблице/диаграмме (не CV); скелет задания 4;
- короткий чек-лист объёма (90–154 / 180–275 / 12–15 фраз);
- список того, что тьютор будет требовать по языку **сразу**, хотя это ещё не «модуль 1»: только оформление письма и запрет ломать план. Языковые темы модулей ещё не начаты.

## Что вводный модуль не делает

- не учит Present Simple как первый грамматический блок — это модуль 1;
- не даёт полноценный КИМ;
- не различается для двух годов по содержанию видео. Различается только следующий шаг после него.

## Рекомендуемый порядок внутри модуля

1. Видео-навигатор (готовые слайды + речь).
2. Памятка маршрута: твой год, список модулей.
3. Три скелета продуктов + 1 удачный и 1 неудачный пример на каждый (когда появятся «мр Пч» и «мр Уч»).
4. Короткий входной Quiz на формат: где стоит запятая в письме, сколько абзацев в эссе, какие 4 аспекта в задании 4. Это не диагностика года, это допуск к пониманию критериев.
