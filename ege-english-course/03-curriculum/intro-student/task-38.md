# Вводный модуль — задание 38 (для ученика)

Эссе **в официальном стиле** на основе **таблицы или диаграммы**. Максимум **14** баллов.  
Это не CV и не отдельное деловое письмо.

Полные удачные/неудачные эссе — из «мр Пч», когда файл прикрепят. Ниже — план, который тьютор требует с первой сдачи.

---

## Объём

Целевой **200–250** слов. Допуск **180–275**.  
Меньше 180 → **0 за всё**. Больше 275 → проверяют только первые 250 слов.

---

## Сетка содержания (план)

Каждый пункт плана — **новый абзац**.

| Абзац | Что написать |
| --- | --- |
| 1 | Тема **проекта** + откуда данные (*survey / opinion poll / the table shows*) |
| 2 | 2–3 факта из таблицы **с цифрами** |
| 3 | 1–2 **сравнения** с коротким комментарием по теме |
| 4 | Проблема в этой сфере + **реалистичный** способ её решить |
| 5 | Заключение: своё мнение по заданному аспекту явно (*I think / In my opinion*) |

Стиль: нейтральный, без разговорности, без риторических вопросов, без *gonna*, *kids*, *awesome*.

На курсе в данных или в сравнении будет аспект **про Россию**.

---

## Полезные фразы

- `The table / chart shows the results of a survey on…`
- `According to the data, … percent of respondents…`
- `The most / least popular option is…`
- `Compared with…, … is higher / lower.`
- `One problem in this area is… A possible way to solve it is…`
- `In conclusion, I think…`

---

## Чего не делать

- не пересказывать таблицу без цифр;
- не писать for/against и не писать story;
- не забывать слово *survey* / источник данных во вступлении.
