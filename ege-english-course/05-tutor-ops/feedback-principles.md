# Принципы фидбека тьютора

Единая логика на письмо 37, эссе 38 и задание 4:

1. Подсчёт объёма (порог «0 за всё»).
2. Чек-лист РКЗ по аспектам (`+` / `±` / `−`).
3. Организация.
4. Языковое оформление с разделением ошибок на **комментируем** и **пропускаем**.
5. Итоговые баллы как на ЕГЭ.
6. Текст ученику по шаблону.

Рядом с бланком всегда лежит [накопительный список](../03-curriculum/cumulative-checklist.md) на модуль сдачи.

Для 38 в РКЗ сразу смотрим опору на таблицу/диаграмму, проектную рамку (survey / тема проекта / проблема и решение / вывод) и **официальный стиль**. Формат CV не оцениваем и не требуем.

## Что писать ученику

Шаблонная логика на все три продукта:

- по содержанию — кратко, всё ли раскрыто;
- по организации — абзацы / связки / вход-выход;
- по языку — только пройденные темы, список конкретных исправлений;
- отдельно: «ошибки на будущие темы отметил, пока не учим».

Готовые фразы лежат в бланках.

## Где вести бланки

Автор допускает бумагу или Google Sheets на каждого ученика.  
Поля шапки одинаковые: кому, номер модуля, тема.
