# Бланк тьютора — задание 4 (говорение)

Кому: _________________  
Модуль №: ______  
Тема проекта: _________________________________

Объём: 12–15 фраз.  
< 7 фраз — 0 за всё. 8–9 — максимум 1 по РКЗ. 10–11 — максимум 2. 12–15 — можно 3–4.

## 1. Объём

| Параметр | Результат |
| --- | --- |
| Количество простых предложений (фраз) | _______ |
| Соответствует 12–15? | □ Да / □ Нет (если <7 → 0 баллов) |

## 2. К1 РКЗ (max 4)

| № | Аспект | + / ± / − |
| --- | --- | --- |
| 1 | Выбор фото: краткое описание + различия, связь с темой проекта | □ |
| 2 | Преимущества (1–2) двух видов/типов на фото | □ |
| 3 | Недостатки (1–2) двух видов/типов | □ |
| 4 | Мнение: какой вариант предпочитает (или предпочёл бы / предпочитал в детстве) и почему, эксплицитно | □ |
| | **Итог К1** | ____ / 4 |

- 4 — все 4 аспекта полно, точно, развёрнуто (12–15 фраз);
- 3 — 1 аспект отсутствует **или** 1–2 неточных (12–15 фраз);
- 2 — 1 отсутствует + 1 неточный **или** 3 неточных (10–11 фраз);
- 1 — 1 отсутствует + 2 неточных **или** 2 отсутствуют **или** все неточные (8–9 фраз);
- 0 — 3+ аспектов нет, или ≤7 фраз, или иные комбинации.

## 3. К2 Организация (max 3)

| Параметр | Оценка |
| --- | --- |
| Вступительная фраза с обращением к другу (Hello / Hi …) | □ Есть / □ Нет |
| Заключительная фраза (прощание) | □ Есть / □ Нет |
| Логичность | _____ ошибок |
| Средства логической связи | _____ ошибок |
| **Итог К2** | ____ / 3 |

- 3 — есть вступление и заключение, 0–1 ошибка логики/связок;
- 2 — есть вступление и заключение, 2–3 ошибки;
- 1 — нет вступления **или** заключения (одно есть) и/или 4–5 ошибок;
- 0 — нет ни вступления, ни заключения и/или 6+ ошибок.

## 4. К3 Язык (max 3)

Считаются комплексно лексико-грамматические и фонетические. Для каждого типа — общее число, затем «комментируем / пропускаем».

Итог К3 ____ / 3

- 3 — ≤3 негрубых ЛГ и ≤3 негрубых фонетических;
- 2 — 4–5 ЛГ (≤2 грубых) и/или 4–5 фонетических (≤2 грубых);
- 1 — 6–7 ЛГ (≤3 грубых) и/или 6–7 фонетических (≤3 грубых);
- 0 — 8+ ЛГ или 4+ грубых, или 8+ фонетических или 4+ грубых фонетических.
