# Источник: методические материалы ФИПИ, письменная речь ЕГЭ-2025

Авторский файл в чате: `angl_yaz_pch_mr_ege_2025` («мр Пч»).

Полное название документа: методические материалы для председателей и членов предметных комиссий по проверке заданий с развёрнутым ответом, **раздел «Письменная речь»**, 2025 (Вербицкая, Махмурян и др.). «Пч» здесь — **письменная часть**, не «учащиеся».

В курс **не копируем** 175 страниц экспертного практикума. Для ученика во вводном модуле взяты:

- формулировка и объём заданий 37 и 38 (цель 100–140 / 200–250; допуск 90–154 / 180–275);
- правило: 0 по содержанию → всё задание 0; превышение объёма → проверяют только первые 140 / 250 слов;
- дополнительные схемы: 6 аспектов письма, 6 аспектов эссе;
- стиль 37: `Dear` / `Hi` + имя; `Hey` не принимается; подпись только имя; без адреса и даты;
- стиль 38: нейтральный официальный; во вступлении проект + источник данных (*survey / opinion poll*);
- удачное письмо № 8311 (6/6, *St. Petersburg*);
- письмо на 5/6 (еда / Сандра) и на 3/6 (кемпинг / Эмили);
- неудачные письма № 8447 (`Hey`, 0/6) и № 4798 (транслит названий книг + лишний объём, 0/6);
- удачное эссе № 1025 (12/14, музыкальные школы в Zetland);
- эссе № 5806 (10/14: длиннее 275, заключение выпало);
- неудачное эссе № 8781 (0/14, Новый год в Zetland).

Устная часть разобрана отдельно: [mr-uch-oral.md](mr-uch-oral.md).

Права ФИПИ: в репозитории — пересказ и учебные выдержки для курса, не скан пособия.
