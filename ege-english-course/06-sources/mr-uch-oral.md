# Источник: методические материалы ФИПИ, устная часть ЕГЭ-2025

Авторский файл в чате: `angl_yaz_uch_mr_ege_2025` («мр УЧ»).

Полное название документа: методические материалы для председателей и членов предметных комиссий по проверке заданий с развёрнутым ответом, **раздел «Говорение»**, 2025 (Вербицкая, Махмурян). «УЧ» здесь — **устная часть**, не «учащиеся».

В курс **не копируем** 124 страницы экспертного практикума. Для ученика во вводном модуле взяты:

- формулировка задания 4 (2024–2025): фото нельзя переслать, только голосовое;
- четыре аспекта содержания и сетка 4+3+3;
- порог 12–15 фраз / ноль при ≤7;
- правило: 0 по содержанию → всё задание 0;
- шаблон монолога;
- удачный ответ № 0487 (9/10, *Summer holidays*);
- неудачные фрагменты (*Shopping*) и ответ № 9213 (0/10, *Family pastime*).

Письменная часть («мр Пч») в комплект пока не приложена — примеры 37/38 ждут её.

Права ФИПИ: в репозитории — пересказ и учебные выдержки для курса, не скан пособия.
