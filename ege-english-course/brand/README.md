# Фирменный стиль «Английский Маяк»

Цвета — из файла дизайнера. Логотип — цветной вариант названия с круглой маркой (маяк).

## Палитра

| Hex | Роль |
| --- | --- |
| `#214149` | основной тёмно-бирюзовый: заголовки, тёмные слайды |
| `#468A9D` | бирюза: подзаголовки, ссылки, теги |
| `#A5D2DF` | небо: вторичный акцент, текст на тёмном фоне |
| `#C19B4F` | золото: линии, маркеры, рамки акцентов |
| `#F3D593` | светлое золото: заголовки на тёмном фоне |
| `#494F55` | уголь: основной текст |
| `#A8B2BB` | сталь: второстепенный текст, линии таблиц |
| `#FFFFFF` | белый: фон документов и контентных слайдов |
| `#488DA0` → `#1A333A` | градиент бирюзы (круг логотипа) |
| `#C19B4F` → `#F3D593` | градиент золота (лучи маяка) |

Свотчи: [palette.svg](palette.svg).

## Логотип

Используйте **цветной** lockup на светлом фоне, не инверсию на чёрном.

| Файл | Где ставить |
| --- | --- |
| [logo-stack.png](logo-stack.png) | обложка PDF, титульный слайд по центру |
| [logo-row.png](logo-row.png) | шапка документа и правый верх контентного слайда |
| [logo-icon.png](logo-icon.png) | подвал, тёмные слайды-разделы, маленькая марка |

Исходники SVG: `logo-icon.svg`, `logo-row.svg`, `logo-stack.svg`.

Пересобрать PNG:

```bash
python3 ege-english-course/scripts/export_brand_assets.py
```

## Шаблоны

| Файл | Что это |
| --- | --- |
| [шаблон-документа.pdf](шаблон-документа.pdf) | макет PDF: шапка с цветным названием, иерархия, таблица, цитата |
| [шаблон-презентации.pptx](шаблон-презентации.pptx) | 6 слайдов 16:9: титул, раздел, список, две колонки, акцент, таблица |

Собрать оба:

```bash
python3 ege-english-course/scripts/brand_templates.py
```

Все PDF курса из Markdown получают ту же шапку и подвал:

```bash
python3 ege-english-course/scripts/md_to_pdf.py
```

Презентация вводного модуля:

```bash
python3 ege-english-course/scripts/intro_student_presentation.py
```
