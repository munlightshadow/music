# Фирменный стиль «Английский Маяк»

Цвета — из файла дизайнера.

## Два кадра логотипа

| Кадр | Фон страницы | Что ставим |
| --- | --- | --- |
| **Frame 5** (светлый) | белая / светлая | цветной диск + тёмно-бирюзовое «АНГЛИЙСКИЙ МАЯК» |
| **Frame 4** (тёмный) | чёрная / тёмная | ночной диск + бирюзовое «АНГЛИЙСКИЙ МАЯК» |
| **Титул** | синий градиент брендбука | маяк белый с жёлтым, справа внизу |

Вектор светлого кадра: [logo-source.pdf](logo-source.pdf) / [logo-frame5.pdf](logo-frame5.pdf). Frame 4 собирается из той же геометрии маяка: ночное небо, белая башня, чёрный купол, бирюзовая обводка и бирюзовый набор.

| Файл | Где ставить |
| --- | --- |
| [logo-stack.png](logo-stack.png), [logo-row.png](logo-row.png), [logo-icon.png](logo-icon.png) | светлые страницы — **Frame 5** |
| [logo-stack-on-dark.png](logo-stack-on-dark.png), [logo-row-on-dark.png](logo-row-on-dark.png) | чёрный фон — полный **Frame 4** |
| [logo-icon-on-dark.png](logo-icon-on-dark.png) | тёмно-бирюзовые слайды — диск **Frame 4** (без наборного текста: бирюза на `#214149` пропадает) |
| [logo-mark.png](logo-mark.png) + [cover-bg.png](cover-bg.png) | титул |

## Палитра

| Hex | Роль |
| --- | --- |
| `#214149` | основной тёмно-бирюзовый: заголовки, тёмные слайды |
| `#468A9D` | бирюза: подзаголовки, ссылки, набор Frame 4 |
| `#A5D2DF` | небо: вторичный акцент, текст на тёмном фоне |
| `#C19B4F` | золото: линии, маркеры, рамки акцентов |
| `#F3D593` | светлое золото: заголовки на тёмном фоне |
| `#494F55` | уголь: основной текст |
| `#A8B2BB` | сталь: второстепенный текст, линии таблиц |
| `#FFFFFF` | белый: фон документов и контентных слайдов |
| `#488DA0` → `#1A333A` | градиент бирюзы (титул) |
| `#C19B4F` → `#F3D593` | градиент золота (лучи маяка) |
