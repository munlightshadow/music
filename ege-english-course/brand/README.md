# Фирменный стиль «Английский Маяк»

Цвета — из файла дизайнера.

## Два кадра логотипа

Светлый кадр — **светлый круг** вокруг маяка. Тёмный кадр — **тёмный круг** вокруг маяка.

| Кадр | Круг | Фон страницы | Файлы |
| --- | --- | --- | --- |
| **светлый** | бледное небо | белая / светлая | [logo-stack.png](logo-stack.png), [logo-row.png](logo-row.png), [logo-icon.png](logo-icon.png) |
| **тёмный** | бирюзовое небо | тёмная / чёрная | [logo-stack-on-dark.png](logo-stack-on-dark.png), [logo-row-on-dark.png](logo-row-on-dark.png), [logo-icon-on-dark.png](logo-icon-on-dark.png) |
| **титул** | без круга | синий градиент брендбука | [logo-mark.png](logo-mark.png) + [cover-bg.png](cover-bg.png) |

На слайдах `#214149` ставим только диск тёмного кадра: набор `#214149` на том же цвете не читается.

Исходники: [logo-frame-light.pdf](logo-frame-light.pdf), [logo-frame-dark.pdf](logo-frame-dark.pdf). PNG вырезаются из растра страницы (вектор в PDF неполный). `logo-source.pdf` — копия светлого.

## Палитра

| Hex | Роль |
| --- | --- |
| `#214149` | основной тёмно-бирюзовый: заголовки, тёмные слайды |
| `#468A9D` | бирюза: подзаголовки, ссылки, теги |
| `#A5D2DF` | небо: вторичный акцент, текст на тёмном фоне |
| `#C19B4F` | золото: линии, маркеры, рамки акцентов |
| `#F3D593` | светлое золото: заголовки на тёмном фоне |
| `#494F55` | уголь: основной текст |
| `#A8B2BB` | сталь: второстепенный текст, линии таблиц |
| `#FFFFFF` | белый: фон документов и контентных слайдов |
| `#488DA0` → `#1A333A` | градиент бирюзы (титул) |
| `#C19B4F` → `#F3D593` | градиент золота (лучи маяка) |

Свотчи: [palette.svg](palette.svg).

```bash
python3 ege-english-course/scripts/export_brand_assets.py
```
