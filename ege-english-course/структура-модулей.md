# Расширенная таблица curriculum (модули 0–20)

Это рабочая карта для производства уроков. Краткая сетка — [сетка-модулей.md](сетка-модулей.md). Здесь каждая линия расписана формулой:

**из юнита** + **добавить** + **убрать как цель**.

«Убрать как цель» значит: страница учебника может мелькнуть, но это **не входит в тренажёры, накопительный список тьютора и фидбек**.

Буквы кодификатора (А, Б, Р…) и номера вроде «А.2» здесь не используем: пишем полные названия тем речи и конкретные звуки / навыки фонетики.

Учебники:

- модули **1–10** — *Solutions Intermediate 3rd edition* (Introduction + Units 1–9);
- модули **11–20** — *Solutions Upper-Intermediate 3rd edition* (Introduction + Units 1–9).

В каждом рабочем модуле два страноведческих блока:

- **Россия** — лонгрид; закрывает родную страну (география, столица, города, регионы, образование, достопримечательности, культура, история, вклад в культуру/науку/технику, выдающиеся люди).
- **English World** — несколько коротких текстов; закрывает страны изучаемого языка по тем же осям.

Culture Bank Solutions — необязательное доп. чтение, не дословная замена English World.

## Как читать столбцы

| Столбец | Что внутри |
| --- | --- |
| Тема речи | Полные формулировки тематического содержания, не буквы. Несколько тем в одном модуле — нормально. |
| Лексика | Слова и сочетания юнита + добор кодификатора + что не учим (идиомы, деловая лексика, compounds как навык). |
| Грамматика | Конструкции юнита + дыры кодификатора, которые сюда логично вставить + что выбрасываем (Conditional III, Future Perfect, инверсия…). |
| Словообразование | Только аффиксация. Словосложение и конверсию не делаем целью. |
| Фонетика | Звуки, ударение, тон, паузы — своими именами и парами вроде peak–pick. |
| Чтение / аудирование | Стратегия юнита, пересаженная на формат КИМ. |
| Россия | **Лонгрид + автоупражнения** по подтемам кодификатора о родной стране + вопрос в 37 / 38 / 4. |
| English World | **Три коротких текста** на тему модуля про разные англоязычные страны + автоупражнения. |
| Продуктивная часть | Всегда формат ЕГЭ, не жанр Solutions (blog, review, for/against…). |
| Zoom | Живая речь; сюда уходят role-play и interview учебника. |

Инварианты каждого рабочего модуля: рецептивная фаза → Zoom → 37 + 38 + задание 4 тьютору → автотест. РКЗ и организация — полностью с первой сдачи. Язык — только по пройденным столбцам 1…N.
